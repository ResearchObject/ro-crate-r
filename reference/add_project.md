# Add project metadata

Add project metadata

## Usage

``` r
add_project(rocrate, name, description = NULL)
```

## Arguments

- rocrate:

  RO-Crate object, see
  [rocrate](https://github.com/ResearchObject/ro-crate-r/reference/rocrate.md).

- name:

  Project's name.

- description:

  Optional, project's description.

## Value

Updated RO-Crate object.
