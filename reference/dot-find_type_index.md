# Find `@type` index in RO-Crate

Find `@type` index in RO-Crate. Useful to retrieve entities with a
particular type in the RO-Crate.

## Usage

``` r
.find_type_index(rocrate, type)
```

## Arguments

- rocrate:

  RO-Crate object, see [rocrate](rocrate.md).

## Value

Boolean vector with index for entity(ies) with `@type`.
