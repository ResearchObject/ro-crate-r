# Summary of an RO-Crate

Provides a summary of the contents of an RO-Crate, including the number
of entities, files and basic metadata information.

## Usage

``` r
# S3 method for class 'rocrate'
summary(object, ...)
```

## Arguments

- object:

  An object of class "rocrate".

- ...:

  Additional arguments (unused).

## Value

An object of class "summary.rocrate".
