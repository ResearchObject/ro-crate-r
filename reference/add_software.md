# Add software application entity

Add software application entity

## Usage

``` r
add_software(rocrate, name, version = NULL)
```

## Arguments

- rocrate:

  RO-Crate object, see
  [rocrate](https://github.com/ResearchObject/ro-crate-r/reference/rocrate.md).

- name:

  Software name.

- version:

  Version string.

## Value

Updated RO-Crate object.
