# Add README file to an RO-Crate

Add README file to an RO-Crate

## Usage

``` r
add_readme(rocrate, text, filename = "README.md")
```

## Arguments

- rocrate:

  RO-Crate object, see
  [rocrate](https://github.com/ResearchObject/ro-crate-r/reference/rocrate.md).

- text:

  Character vector with README content.

- filename:

  README filename.

## Value

Updated RO-Crate object.
